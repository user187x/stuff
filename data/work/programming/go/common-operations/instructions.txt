6. Developer Fundamentals: The Go Cookbook
Setup and Execution:

Initialize: go mod init gocookbook

Add Dependencies: Go doesn't have a built-in password masking function in the standard library, so we use the official Go term package. Run:
go get golang.org/x/term

Run on the fly: go run main.go
